QUIC over Direct Sockets API

⚠️ Important: This application requires:
  • Chrome/Chromium browser with Direct Sockets API enabled
  • Must be run as an Isolated Web App (IWA)
  • Direct Sockets permission in the manifest

This demo runs the quinn QUIC implementation compiled to WebAssembly, using the Direct Sockets API for UDP communication. Unlike the WebSocket relay version, this connects directly to QUIC servers without any intermediary.
